# gondor

A host-ops application composed from
[assay-hostops](https://github.com/developerinlondon/assay-hostops) with
application-specific branding, services, and pages. Runs on
[`assay`](https://github.com/developerinlondon/assay) and
[`assay-engine`](https://github.com/developerinlondon/assay) as a systemd unit on a
managed host.

This repo holds only application-specific pieces. The shared host-ops dashboard
surface lives upstream in `assay-hostops`.
